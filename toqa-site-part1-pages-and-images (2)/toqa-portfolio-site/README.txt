Toqa Fathey portfolio website (new, standalone project)
=========================================================

STATUS: preview only. Nothing has been published or deployed.

What is in this folder
- index.html    the whole website (one page, works on desktop and mobile)
- assets/       every image and video the page uses

  assets/illustrative/   AI-generated images. The page labels each one "Illustrative".
  assets/about/          your portrait
  assets/al-mohamadia/   posts, calendar, tracker, website articles, reels
  assets/vet-home/       posts and the Eid al-Adha campaign
  assets/clav57/         posts and shoot-day photos
  assets/najm/           Najm Digital Marketing posts, presenter video, intro video

Each client has its own folder, so work from different clients is never mixed.

To look at it on your computer: open index.html in a browser (fonts load from Google Fonts when online).

To change a picture: replace the file in assets/ with a new one that has the same name.
To change the email address: search index.html for the address and edit it.

Publishing: not done. When you approve the design, the folder can be put on any static host
(for example Netlify Drop, Cloudflare Pages or GitHub Pages) by uploading it as it is.
